德語數字與標價四大規則

  • 兩位數「由後往前」念：
    39 = neununddreißig（先念 9，再用 und 連接 30）。
  • 千位數用句點 . 分隔：
    2.312 讀作 zweitausenddreihundertzwölf（整串寫在一起不空格）。
  • 價格小數點用逗點 ,：
    8,50 € 讀作 acht Euro fünfzig（中間的 Euro 代替小數點，Cent 常省略）。
  • 「百萬」單獨加空格與複數：
    1.000.000 = eine Million；兩百萬以上用複數 zwei Millionen。
1 的變化注意：
單純數數：eins
接百/千：einhundert / eintausend
接歐元：ein Euro（不加 s）

掌握第三章兩大文法核心：(1) 四種冠詞在「陽／中／陰性」主格下的變化規則；(2) 用 er / es / sie 取代前面提過的名詞。

1. 冠詞體系切換對照表（Nominativ 主格）

2. 人稱代名詞替換機制（Artikel und Personalpronomen）

為了避免重複念同一個名詞，德語依據名詞的「文法性別」替換為第三人稱代名詞：er / es / sie（中文皆譯為「它」）。

der ➔ er
陽性名詞改用 er
Der Kuli ist sehr schön.
→ Er funktioniert auch gut.
這支原子筆很漂亮。它也很好寫。
das ➔ es
中性名詞改用 es
Das Handy kostet 95 Euro.
→ Es hat auch eine Kamera.
這支手機要 95 歐元。它還有相機功能。
die ➔ sie
陰性名詞改用 sie
Die Waschmaschine ist neu.
→ Sie wäscht sehr gut.
這台洗衣機是新的。它洗得非常乾淨。
